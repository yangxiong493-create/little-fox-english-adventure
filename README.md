# 小狐英语岛 · iPad 英语冒险

面向 5 岁、英语零基础儿童的英语启蒙冒险游戏。孩子跟着小狐完成故事任务，在点击、寻找和赠送宝物的过程中自然听懂英语。

当前版本已完成 6 个阶段、59 个可玩任务：

- 阶段 0「小狐之家」：3 个任务，学习 Hello / Bye-bye 和最基础的操作方式。
- 阶段 1「宝物花园」：12 个任务，认识 apple、ball、cat、dog、car、milk，并在组合任务中反复迁移。
- 阶段 2「行动森林」：12 个任务，听懂 find、give、put、jump、stop、red、blue，并马上做出动作。
- 阶段 3「彩色山谷」首批：5 个任务，把已知颜色、物品和大小组合成 red apple、blue ball、big dog、small cat。
- 阶段 4「快乐小镇」：15 个任务，用 I want…、Here you are、Thank you、I like… 和 I’m happy 完成有结果的简单交流。
- 阶段 5「故事城堡」：12 个任务，把熟悉的英语连成三到六步小故事，并迁移到新场景。
- 每关流程：故事引导 → 认识声音 → 游戏挑战 → 可选跟说 → 世界变化与亲子任务。
- 答错不会扣分；引导会逐步增强，最后由小狐陪孩子一起完成。
- 每次挑战都会在本机留下“学习脚印”：记录是否独立完成、用了几级提示、是否由小狐协助，以及是否在新场景中再次听懂。
- 完成故事不直接等于学会；系统会区分“见过、独立辨认、换场景会用、隔一段时间还记得”，并在合适时间推荐已完成故事进行自然复习。关闭声音时仍可推进故事，但不生成听辨学习证据。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端显示的地址。推荐使用 iPad 横屏，也兼容竖屏。

内容和生产构建校验：

```bash
npm run check
```

## 安装到 iPad

发布后的版本是可安装 PWA：

1. 用 iPad 的 Safari 打开线上地址。
2. 点击 Safari 的“分享”按钮。
3. 选择“添加到主屏幕”。
4. 以后直接点击“小狐英语”图标运行。

首次在线完整打开并等待片刻后，界面与全部固定语音会缓存在 iPad 上；之后没有网络也能进入游戏。故事进度、学习证据和复习安排只保存在设备本地。

## 版本说明

- 主要触控区域为 56px 以上，并适配 iPad 安全区。
- 186 条固定中英语音由 MiniMax `speech-2.8-hd` 的 A 女声 `lovely_girl` 预先生成并随应用打包；其中包含中文玩法引导、英文学习输入和角色反馈，播放时不会上传儿童语音或文字。
- 提前解码必要与下一关语音，最多保留 64 条解码缓存；全部固定语音仍由 PWA 缓存用于离线播放。播放单词时防止连点提前累计次数，成功语音完整结束后才推进下一步。
- 欢迎页和冒险地图使用完整的儿童轻音乐《Spring Field》，随应用离线打包，不再使用短循环合成声。进入正式关卡或播放任何中英文人声时，背景音乐会完全停止发声；关闭游戏声音会同时停止人声和音乐。
- 如果固定音频因设备异常无法解码，才会使用系统内置语音作为后备；若设备暂时不允许音频启动，游戏流程也不会卡死。
- “说一说”环节是无录音交互原型，不会请求麦克风权限。
- 家长入口使用简单成人门，测试答案为 `5`。
- 学习进度只保存在当前设备中，不会上传儿童数据；保存不可用时会显示提示。
- 中途离开后可继续当前环节和挑战小步，已经使用的提示也会保留。“认识声音”环节会从该环节重新听。
- 新版本在欢迎页或地图提示更新，不会在关卡中强制刷新。开发环境的 `?previewMission=任务编号` 不写入真实存档。
- 旧版 `v2` / `v3` / `v4` 故事进度会自动迁移；已经完成彩色山谷的家庭可直接继续快乐小镇，但旧数据只推断为“见过”，不会伪造独立掌握证据。
