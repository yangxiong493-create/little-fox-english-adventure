# 小狐英语岛 · iPad 互动原型

面向 5 岁儿童的英语启蒙冒险游戏原型。核心流程为：冒险地图 → 故事任务 → 听音选择 → 拖拽互动 → 跟读 → 奖励与线下任务。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端显示的地址。推荐使用 iPad 横屏，也兼容竖屏。

## 安装到 iPad

发布后的版本是可安装 PWA：

1. 用 iPad 的 Safari 打开线上地址。
2. 点击 Safari 的“分享”按钮。
3. 选择“添加到主屏幕”。
4. 以后直接点击“小狐英语”图标运行。

首次完整打开后，页面资源会缓存在 iPad 上；没有网络时仍可进入游戏。学习星星和完成状态也会保存在设备上。

## 原型说明

- 主要触控区域为 56px 以上，并适配 iPad 安全区。
- 英语语音使用浏览器内置 Speech Synthesis，不上传任何数据。
- “说一说”环节是无录音交互原型，不会请求麦克风权限。
- 家长入口使用简单成人门，测试答案为 `5`。
- 学习进度只保存在当前设备中，不会上传儿童数据。
