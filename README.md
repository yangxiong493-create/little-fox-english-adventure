# 小狐英语岛 · iPad 英语冒险

面向 5 岁、英语零基础儿童的英语启蒙冒险游戏。孩子跟着小狐完成故事任务，在点击、寻找和赠送宝物的过程中自然听懂英语。

当前 MVP 已完成 2 个阶段、15 个可玩任务：

- 阶段 0「小狐之家」：3 个任务，学习 Hello / Bye-bye 和最基础的操作方式。
- 阶段 1「宝物花园」：12 个任务，认识 apple、ball、cat、dog、car、milk，并在组合任务中反复迁移。
- 每关流程：故事引导 → 认识声音 → 游戏挑战 → 可选跟说 → 世界变化与亲子任务。
- 答错不会扣分；引导会逐步增强，最后由小狐陪孩子一起完成。

在线版本：[打开小狐英语岛](https://yangxiong493-create.github.io/little-fox-english-adventure/)

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端显示的地址。推荐使用 iPad 横屏，也兼容竖屏。

内容和生产构建校验：

```bash
npm run check
```

## 安装到 iPad

发布后的版本是可安装 PWA：

1. 用 iPad 的 Safari 打开线上地址。
2. 点击 Safari 的“分享”按钮。
3. 选择“添加到主屏幕”。
4. 以后直接点击“小狐英语”图标运行。

首次在线完整打开并等待片刻后，界面与全部固定语音会缓存在 iPad 上；之后没有网络也能进入游戏。学习星星和完成状态保存在设备本地。

## 版本说明

- 主要触控区域为 56px 以上，并适配 iPad 安全区。
- 51 条固定英语语音由 MiniMax `speech-2.8-hd` 的 A 女声 `lovely_girl` 预先生成并随应用打包；播放时不会上传儿童语音或文字。
- 如果固定音频因设备异常无法播放，才会使用系统内置语音作为后备。
- “说一说”环节是无录音交互原型，不会请求麦克风权限。
- 家长入口使用简单成人门，测试答案为 `5`。
- 学习进度只保存在当前设备中，不会上传儿童数据。
